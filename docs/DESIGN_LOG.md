# Design log

The author directs and reviews the design. Build choices are first logged as **Proposed**; when the owner accepts,
changes or rejects one, the entry is updated with that decision and the date. All entries below have been reviewed.

| # | Date | Decision | Status | Reason |
|---|---|---|---|---|
| 1 | 2026-11-14 | Plain JavaScript ES modules with JSDoc, no framework and no bundler, instead of TypeScript | **Accepted by the author** (2026-11-14) | Smallest download (about 61 kB gzip first load), no build toolchain to maintain, runs unchanged from any static host. Brief section 6 recommends TypeScript; changing later is possible. |
| 2 | 2026-11-14 | Stream SPHEREx pixels from IRSA's public S3 bucket with HTTP byte ranges, decoding FITS, TAN-SIP WCS, WAVE-TAB and RICE_1 flags in the browser | **Accepted by the author** (2026-11-14) | The bucket allows CORS and range requests, so no server is needed for imagery; IRSA's cutout service has no CORS and returns large ePSF tables. |
| 3 | 2026-11-14 | Search with IRSA TAP (`spherex.artifact` ⋈ `spherex.plane`, CONTAINS on `poly`) through an allow-listed relay | **Accepted by the author** (2026-11-14) | TAP sees new data at ingestion (SIA lags ~1 day) and covers every release without naming them; TAP has no CORS. |
| 4 | 2026-11-14 | One relay codebase (`relay/core.mjs`) packaged for several free hosts, with a list of relays in `config.json` and automatic failover | **Accepted by the author** (2026-11-14) | No single host or machine is required; a second relay is the fallback the brief asks for. |
| 5 | 2026-11-14 | Default frames = one co-add per six-month survey pass; per-detector co-adds combined with equal weight | **Accepted by the author** (2026-11-14) | Matches SPHEREx's six-month cadence, maximises signal-to-noise, keeps wavelength mix comparable between epochs. |
| 6 | 2026-11-14 | Difference images are matched detector by detector (wavelength-matched) | **Accepted by the author** (2026-11-14) | Brief 4.3 asks for wavelength-matched differences. |
| 7 | 2026-11-14 | Flags read only around the target by default; whole-field flag map when the flags overlay is on | **Accepted by the author** (2026-11-14) | Cuts transfer by about a third while keeping photometry clean. |
